Control software
====

This directory contains the software that runs on the car (v2, international final). The full architecture is in the [top-level README](../README.md#7-software-architecture) (§7 software, §8 route mode, §9 digital twin); build and run steps in [§12](../README.md#12-how-to-build-and-run). The v1 (national final) software is described in [`docs/v1-national/README.md`](../docs/v1-national/README.md) and tagged `v1.0-nacional`.

Two controllers, linked by UART at 460 800 baud:

- **Raspberry Pi 5** — camera, pillar mapping, localization and route planning. Entry point [`RASPI/cam/pure_pursuit/runtime_nuevo.py`](RASPI/cam/pure_pursuit/runtime_nuevo.py) (run by the `wro-runtime` service).
- **ESP32** — real-time control: speed loop, steering, pure pursuit on the route sent by the Pi, corners, start and parking.

## ESP32 (`ESP32/`)

| Sketch | Use |
|---|---|
| [`PurePursuit/`](ESP32/PurePursuit/PurePursuit.ino) | Main firmware, development version (obstacle round, route mode) |
| [`PurePursuitCarrera/`](ESP32/PurePursuitCarrera/) | **Race build** of the obstacle round: `PurePursuit.ino` + the tuned parameters, generated by `twin/tools/exportar_carrera.py`. Don't edit by hand |
| [`RondaAbierta/`](ESP32/RondaAbierta/RondaAbierta.ino) | **Open Challenge**, ESP32 only (ToF + BNO085) |
| [`SeguirRuta/`](ESP32/SeguirRuta/) | Route-following bench: a route over Bluetooth, followed with odometry |
| [`CalibFox/`](ESP32/CalibFox/), [`VueltaCalibracion/`](ESP32/VueltaCalibracion/), [`ServoCentro/`](ESP32/ServoCentro/) | Calibration: servo center and radius, encoder, ToF along a lap |
| `*Test/`, [`PinScan/`](ESP32/PinScan/), [`TofId/`](ESP32/TofId/) | Component bring-up (encoder, ToF, BNO085, motor, servo, UART pins) |
| [`Controller_PI/`](ESP32/Controller_PI/), [`_archive/`](ESP32/_archive/), `UltrasonicTest/`, `DistanceTest/` | v1 hardware, kept for history |

## Raspberry Pi (`RASPI/cam/`)

| Module | Use |
|---|---|
| [`vision.py`](RASPI/cam/vision.py), [`camera_tuning/`](RASPI/cam/camera_tuning/) | Camera capture (Picamera2), lens shading, fixed exposure, pillar color detection |
| `pure_pursuit/runtime_nuevo.py`, `config.py`, `carrera.json` | Main loop and parameters (`carrera.json` = race overrides exported from the twin) |
| `pure_pursuit/bev.py`, `color_corr.py`, `corner_lines.py` | Bird's-eye view, floor-referenced color correction, orange/blue line detection |
| `pure_pursuit/digital_map.py`, `seat_roi.py`, `wro_field.py` | Track model and pillar seats |
| `pure_pursuit/localizer.py`, `odometry.py` | EKF pose from encoder + BNO085 + ToF ray-cast against the map |
| `pure_pursuit/route_mode.py`, `ring_route.py`, `route_planner.py` | Route mode: dynamic-programming route, B-spline, speed profile |
| `pure_pursuit/start_fix.py`, `salida_cajon.py` | Blind start: parking-lot position and exit |
| `pure_pursuit/bev_recorder.py` | Per-run recording (video + clean BEV) |
| `pure_pursuit/calibrate.py`, `calibra_luz.py`, `mide_exposicion.py`, `cam_web.py` | Venue calibration (BEV, colors, exposure, browser view) |
| `pure_pursuit/chassis_twin.py`, [`twin/`](RASPI/cam/pure_pursuit/twin/) | Digital twin: real firmware + real runtime in a simulator, benches, tests |
| `obstacle_memory.py`, `centerline.py`, `corner_planner.py`, `controller.py`, `wro_runtime.py`, `_archive/` | v1 pipeline (national final), kept for history and fallback |

## Quick run

```bash
cd ~/FoxRobotics && source .venv/bin/activate && cd src/RASPI/cam
python -m pure_pursuit.runtime_nuevo --serial-port /dev/ttyAMA0 --no-window \
    --record-orillas --record-output ~/FoxRobotics/videos_orillas
```

```bash
arduino-cli compile --fqbn esp32:esp32:esp32 src/ESP32/PurePursuitCarrera
arduino-cli upload  --fqbn esp32:esp32:esp32 -p <PORT> src/ESP32/PurePursuitCarrera
```

Autostart: `scripts/install_autostart_pi.sh` installs `deploy/systemd/wro-runtime.service`.
