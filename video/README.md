Video
====

This directory must contain the video.md file with a URL to YouTube (should be either public or accessible by link) showing the vehicle driving autonomously.
That part of the video where driving demonstration exists must be at least 30 seconds in length.

The links are in [`video.md`](video.md). [`portadas/`](portadas/) has the thumbnails of the v2 videos and the script that draws them and the README banner (`python video/portadas/portada.py`; `portadas/editor/` is the brush editor used to cut the car out of the photo).
